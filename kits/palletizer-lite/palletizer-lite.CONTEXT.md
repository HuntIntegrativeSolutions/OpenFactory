## Commands

Run these from the folder that holds this file. In the OpenFactory source repository,
put `uv run` in front of each.

```bash
openfactory validate palletizer-lite.yaml
openfactory lint palletizer-lite.yaml --script palletizer-lite.py
openfactory test palletizer-lite.yaml --script palletizer-lite.py   # grade the stand-in script
openfactory test palletizer-lite.yaml --plc   # grade a real PLC, in real time
openfactory run palletizer-lite.yaml   # protocol server and viewer; a PLC drives it
openfactory run palletizer-lite.yaml --script palletizer-lite.py   # the stand-in script drives it
openfactory run palletizer-lite.yaml --as-fast-as-possible --duration 60   # headless
openfactory export palletizer-lite.yaml -o palletizer-lite-io.csv --analog-encoding float32
openfactory export palletizer-lite.yaml -o palletizer-lite-io-int16.csv --analog-encoding int16_scaled
openfactory export palletizer-lite.yaml --format l5x -o palletizer-lite-tags.L5X
openfactory export palletizer-lite.yaml --format ignition -o palletizer-lite-ignition-tags.json
openfactory bundle palletizer-lite.yaml   # one .ofz with meshes, lockfiles and script
```

Modbus TCP listens on 127.0.0.1 port 5020 and the viewer on http://127.0.0.1:8000/
unless `openfactory.toml` or `--bind`, `--port` and `--web-port` say otherwise.

## Fault kinds

- `stuck_on`: a DI reads true whatever the device senses (`port=NAME` for one port)
- `stuck_off`: a DI reads false whatever the device senses (`port=NAME` for one port)
- `jammed`: the belt or actuator stops where it is; its feedback stays honest
- `slow`: the belt or actuator moves at `factor` of its speed (default 0.5)
- `misaligned`: the sensor sees `offset_m` late (positive) or early
- `noisy`: random dropouts, `rate` per second (0.5), each `duration_s` long (0.2)
- `drift`: an AI reads `rate` units per second more since the fault (default 0.01)
- Inject one with `--fault ID=KIND[:key=value,...] --fault-at SECONDS` on `run` or
  `test`, or from the viewer's context menu. `--fault comms=drop` and
  `--fault comms=latency:ms=N` stall or delay the protocol server instead.
