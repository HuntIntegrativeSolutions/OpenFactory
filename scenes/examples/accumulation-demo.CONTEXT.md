## Commands

Run these from the folder that holds this file. In the OpenFactory source repository,
put `uv run` in front of each.

```bash
openfactory validate accumulation-demo.yaml
openfactory lint accumulation-demo.yaml --script accumulation-demo.py
openfactory test accumulation-demo.yaml --script accumulation-demo.py   # grade the stand-in script
openfactory test accumulation-demo.yaml --plc   # grade a real PLC, in real time
openfactory run accumulation-demo.yaml   # protocol server and viewer; a PLC drives it
openfactory run accumulation-demo.yaml --script accumulation-demo.py   # the stand-in script drives it
openfactory run accumulation-demo.yaml --as-fast-as-possible --duration 60   # headless
openfactory export accumulation-demo.yaml -o accumulation-demo-io.csv --analog-encoding float32
openfactory export accumulation-demo.yaml -o accumulation-demo-io-int16.csv --analog-encoding int16_scaled
openfactory export accumulation-demo.yaml --format l5x -o accumulation-demo-tags.L5X
openfactory export accumulation-demo.yaml --format ignition -o accumulation-demo-ignition-tags.json
openfactory bundle accumulation-demo.yaml   # one .ofz with meshes, lockfiles and script
```

Modbus TCP listens on 127.0.0.1 port 5020 and the viewer on http://127.0.0.1:8000/
unless `openfactory.toml` or `--bind`, `--port` and `--web-port` say otherwise.

## Fault kinds

- `stuck_on`: a DI reads true whatever the device senses (`port=NAME` for one port)
- `stuck_off`: a DI reads false whatever the device senses (`port=NAME` for one port)
- `jammed`: the belt or actuator stops where it is; its feedback stays honest
- `slow`: the belt or actuator moves at `factor` of its speed (default 0.5)
- `misaligned`: the sensor sees `offset_m` late (positive) or early
- `noisy`: random dropouts, `rate` per second (0.5), each `duration_s` long (0.2)
- `drift`: an AI reads `rate` units per second more since the fault (default 0.01)
- Inject one with `--fault ID=KIND[:key=value,...] --fault-at SECONDS` on `run` or
  `test`, or from the viewer's context menu. `--fault comms=drop` and
  `--fault comms=latency:ms=N` stall or delay the protocol server instead.
